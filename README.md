# Linus Behrbohm

Software engineer focused on systems and platforms with Rust, TypeScript, and
WebAssembly. I work on understandable agent and model processes and interactive
visualization of real data. Based in Hamburg and open to remote or on-site work.

## Highlights

- [workflow-tools](https://github.com/mankinskin/workflow-tools) — Rust CLI and
  MCP tooling for ticket, specification, session, rule, audit, and test workflows.
- [context-engine](https://github.com/mankinskin/context-engine) — workspace
  coordination for graph crates, viewers, operator tooling, and setup.
- [context-agent](https://github.com/mankinskin/context-agent) — a
  Dioxus/WebAssembly and Axum playground with persistent-session work.
- [file-combiner](https://github.com/mankinskin/file-combiner) — a Dioxus/Axum
  application for preparing analyzed artifacts from template and person inputs.
- [memory-viewers](https://github.com/mankinskin/memory-viewers) — user-facing
  ticket/specification viewers with nested viewer and CLI tooling.
